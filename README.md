# SQL Visualizer & Editor

**SQL Visualizer & Editor** — это интерактивный инструмент для визуализации, редактирования и анализа SQL-запросов. Он автоматически преобразует сложные SQL-скрипты, включая CTE (WITH-блоки), соединения (JOIN), подзапросы и агрегации, в наглядные интерактивные блок-схемы (графы), помогая быстро понять логику выполнения запроса.

---

## 🚀 Основные возможности

### 📊 1. Интерактивная визуализация SQL (Граф)
- **Автоматическое построение графа:** Визуализация потоков данных между блоками запроса (таблицы, CTE, JOIN, WHERE, GROUP BY, ORDER BY, LIMIT).
- **Навигация и управление:**
  - Изменение направления графа (слева направо `LR` / сверху вниз `TB`).
  - Масштабирование, мини-карта (Minimap), подгонка под экран (Auto-fit).
  - Сворачивание и разворачивание отдельных узлов графа.
  - Поиск элементов на графе с подсветкой результатов.
  - Экспорт схемы в форматы **PNG** и **SVG**.
- **Двусторонняя связь с кодом:** Клик по узлу графа подсвечивает соответствующие строки SQL в редакторе.

---

### 📝 2. Редактор SQL и работа с файлами
- **Поддержка вкладок:** Удобная работа с несколькими SQL-файлами одновременно (до 9 вкладок).
- **Подсветка и форматирование:**
  - Синтаксическая подсветка SQL.
  - Встроенный форматировщик кода с настройкой отступов и регистра ключевых слов.
  - Включение/отключение переноса строк (Word Wrap).
  - Поиск и замена текста внутри редактора (`Ctrl+F`).
- **Поддержка кодировок:**
  - Открытие файлов в стандартной кодировке **UTF-8** (`Открыть`).
  - Отдельная кнопка **`Win-1251`** для корректного открытия файлов в кириллической кодировке Windows-1251 без иероглифов и «кракозябр».
- **Сохранение:** Быстрое сохранение текущего кода в `.sql` файл на диск.

- **DuckDB**

---

### 🦆 4. Встроенный SQL-движок DuckDB (In-Browser WASM)
- **Локальное выполнение запросов:** Запуск SQL-кода прямо в браузере с помощью WebAssembly без отправки данных на сервер.
- **Анализ файлов:** Анализ и выборка данных напрямую из файлов **CSV**, **Parquet** и **JSON**.
- **Просмотр результатов:**
  - Вывод табличных результатов с пагинацией и ограничением количества строк.
  - Быстрый просмотр структуры таблиц и типов данных.

---

### 📚 5. Сниппеты, Конструктор и История
- **Менеджер сниппетов:** Сохранение часто используемых SQL-шаблонов и фрагментов кода с мгновенной вставкой в редактор.
- **SQL-Конструктор (Пресеты):** Быстрая сборка базовых SQL-конструкций (SELECT, JOIN, GROUP BY и др.).
- **История версий:** Автоматическое сохранение снимков кода для отката к предыдущим версиям.

---

### ⚙️ 6. Персонализация и настройки
- **Темы оформления:** Переключение между светлой и тёмной темами.
- **Гибкая настройка панели инструментов:** Возможность скрывать или отображать любые элементы интерфейса (кнопки открытия, сохранения, форматирования, сниппетов, DuckDB и кнопки `Win-1251`).
- **Горячие клавиши (Hotkeys):**
  - `Ctrl + O` — Открыть файл
  - `Ctrl + S` — Сохранить файл
  - `Ctrl + Enter` — Построить граф / Визуализировать
  - `Ctrl + Shift + F` — Отформатировать SQL
  - Настройка кастомных комбинаций клавиш в окне настроек.
- **Режимы отображения:** Переключение между полноэкранным редактором, разделенным экраном (редактор + граф) и компактной сворачиваемой панелью.

## 🛠 Технологический стек

- **Frontend:** React, TypeScript, Vite
- **Стилизация:** Tailwind CSS, Lucide Icons
- **Графы:** React Flow (`@xyflow/react`)
- **SQL Анализ & Форматирование:** `sql-parser-cst`, `sql-formatter`
- **In-Browser Database:** DuckDB WebAssembly (`@duckdb/duckdb-wasm`)
- **Desktop Framework:** Tauri (Rust)
