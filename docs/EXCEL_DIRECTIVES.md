# Справочник SQL-директив Excel-отчётов

Документ описывает, как приложение читает директивы из SQL-комментариев при экспорте результата в `.xlsx`. Общее описание и пример — в [руководстве пользователя](./USER_GUIDE.md#3-движок-excel-отчетов-и-sql-директивы). English version: [EXCEL_DIRECTIVES_EN.md](./EXCEL_DIRECTIVES_EN.md).

## 1. Как читаются директивы

* Директивы берутся **только из блочных комментариев** `/* ... */`. Комментарии `-- ...` для Excel игнорируются (они нужны для переменных редактора и `-- @job`).
* Тексты всех блочных комментариев запроса склеиваются, поэтому директивы можно раскладывать по нескольким блокам и размещать в любом месте запроса.
* Значение директивы читается до конца строки, но обрывается на символах `@` и `*`. Поэтому в значениях `@file`, `@sheet`, `@preset`, `@split`, `@skip`, `@hide`, `@group`, `@protect` нельзя использовать эти символы (в пароле `@protect` — тоже).
* Регистр: все директивы, кроме `@file` и `@sheet`, распознаются без учёта регистра; `@file` и `@sheet` нужно писать строчными буквами.
* Директивы переопределяют настройки из **Settings → Excel** только для этого экспорта; сохранённые настройки не меняются.
* Порядок применения: сначала `@preset` (заменяет все настройки настройками пресета), затем остальные директивы поверх него.

## 2. Справочник

| Директива | Значение | Что делает | Замечания |
| :--- | :--- | :--- | :--- |
| `# Заголовок` | текст | Заголовок отчёта в первых строках листа; включает вывод заголовка | Берётся первый `#` в блочных комментариях (любой, в том числе в тексте комментария). |
| `## Подзаголовок` | текст | Подзаголовок под заголовком | Выводится только вместе с заголовком. Если задан один `## ...` без `#`, этот текст становится и заголовком, и подзаголовком. |
| `@file: имя` | текст без расширения | Имя файла | К имени добавляется дата: `имя_ГГГГ-ММ-ДД.xlsx`. Без директивы берётся «Имя файла» из настроек (по умолчанию `report`). |
| `@sheet: имя` | текст | Имя листа | До 31 символа; символы `\ / ? * : [ ]` заменяются на `_`. Игнорируется при `@split` (имена листов берутся из значений колонки). По умолчанию `Отчет`. |
| `@preset: имя` | имя пресета | Применяет пресет оформления | Сравнение по имени без учёта регистра. Встроенный пресет называется «По умолчанию». Если пресета с таким именем нет, директива молча игнорируется. |
| `@totals: функция` | `SUM`, `AVERAGE`/`AVG`, `COUNT`/`COUNTA` | Задаёт функцию итогов | Задаёт функцию и для строки, и для столбца итогов, но **не включает** их: строка итогов включена по умолчанию, столбец итогов выключен, включаются в Settings → Excel. `COUNT` выгружается как формула `COUNTA`. |
| `@split: колонка` | имя или номер (с 1) | Один лист на каждое значение колонки | Колонка не попадает на листы. Пустое значение → лист «Пусто». Имя листа до 31 символа, недопустимые символы → `_`, повторы получают суффикс ` (2)`, ` (3)`. Только одна колонка. |
| `@skip: колонка` | имя или номер | Исключает колонку из файла | Только одна колонка. |
| `@hide: колонка` | имя или номер | Скрывает колонку на листе | Данные и формулы остаются. Только одна колонка. |
| `@group: колонка` | имя или номер; `0` — выключить | Группировка подряд идущих строк с одинаковым значением | Строки внутри группы получают уровень структуры Excel (сворачиваются). Сортировка не выполняется: одинаковые значения должны идти подряд (используйте `ORDER BY`). |
| `@group_cols: N` | число | Число колонок-категорий слева | Действует, если в Settings → Excel включён стиль первой колонки (`enableFirstColumnStyle`; по умолчанию выключен). Влияет также на закрепление колонок. |
| `@group_hide: true` | `true`/`false`/`1`/`0` | Не повторять значение группы в дочерних строках | Работает вместе с `@group`. |
| `@protect: пароль` | текст | Защита листа паролем | Включает защиту; разрешены сортировка, автофильтр, изменение ширины колонок и высоты строк. Пароль не должен содержать `@` и `*`. Это защита от случайных правок, а не шифрование. |
| `@excel_save: путь` | путь | *(Десктоп)* Сохраняет файл без диалога | См. раздел 4. |

Номер колонки в `@split`, `@skip`, `@hide`, `@group` считается по исходным колонкам результата (до исключения `@skip` и до удаления колонки `@split`). Значение из одних цифр всегда трактуется как номер, поэтому колонку с именем вида `2024` по имени указать нельзя. Если имя не найдено, директива игнорируется.

## 3. Ограничения

* Не более 1 500 000 ячеек (строки × колонки). При превышении выводится ошибка с просьбой сократить выборку.
* Нет данных — ошибка «Нет данных для экспорта в Excel».
* Тип колонки (число, дата) определяется по типу, который вернула база, а при его отсутствии — по первым 50 непустым значениям.
* Защита `@protect` использует облегчённое хеширование пароля (100 итераций), чтобы экспорт не «подвисал».
* Строка, начинающаяся с `=`, попадает в Excel как формула: так в одном отчёте можно смешивать формулы Excel и SQL, например `SELECT 'Итого' AS name, '=SUM(B2:B10)' AS value`. Это относится и к данным из базы: значение вроде `=== итог ===` или `=1+1` тоже станет формулой (для `=== итог ===` — с ошибкой).

## 4. `@excel_save` (только десктоп)

* Работает только в десктопной версии (Tauri). В других версиях директива игнорируется, файл скачивается обычным способом.
* Путь может быть именем файла (`/reports/out.xlsx`, `D:\reports\out.xlsx`) или папкой с завершающим `/` или `\` (`/reports/`): тогда имя файла формируется как обычно (`имя_ГГГГ-ММ-ДД.xlsx`).
* Файл создаётся автоматически **каждый раз, когда результат запроса приходит в активную вкладку** — в том числе при переходе на другую страницу, смене сортировки или фильтра. В файл попадают ровно те строки, которые вернул запрос: одна страница (по умолчанию 100 строк) или столько, сколько позволяет ваш `LIMIT`. Чтобы выгрузить всё, задайте размер страницы `0` в настройках либо явный `LIMIT`.
* Для запросов в фоновых вкладках выгрузка не выполняется.
* Если запись по заданному пути не удалась, приложение пытается скачать файл обычным способом (через браузерную загрузку).

## 5. Пример

```sql
/*
# Продажи по регионам
## Данные за 2024 год
@file: sales_by_region
@sheet: Продажи
@preset: По умолчанию
@totals: SUM
@group: 1
@group_hide: true
@skip: internal_id
*/
SELECT region, city, revenue, internal_id
FROM sales
ORDER BY region, city;
```

Результат: файл `sales_by_region_<дата>.xlsx`, лист «Продажи», заголовок и подзаголовок сверху, колонка `internal_id` не выгружается, строки сгруппированы по `region` без повторов значения, строка итогов с суммами.
