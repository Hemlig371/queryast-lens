# Исследование данных с Perspective (экспериментально)

Выберите **Исследовать** после **Показать** в меню физической таблицы DuckDB.
Используется текущее подключение Tauri либо WASM (Web/Android). Express/DuckDB,
ClickHouse, VIEW и TEMP не поддерживаются. Произвольный SQL предварительно
сохраните в физическую таблицу через редактор.

**В редактор** сохраняет живое исследование в памяти. Повторное **Исследовать**
для той же таблицы возвращает его; другая таблица заменяет исследование.
Дополнительной строки в редакторе нет. **Закрыть исследование** освобождает Viewer
и клиент, сохраняя исходную таблицу и подключение. При задержке показывается
индикатор без текста в теме Lens. Переподключение закрывает исследование.
**Обновить** перечитывает данные, сохраняя настройки рабочей области. При изменении
схемы может потребоваться закрыть и открыть исследование. Постоянного автосохранения нет.

Новый Viewer использует Pro Light/Pro Dark по теме Lens. Ручной выбор сохраняется
при обновлении. Контейнер наследует шрифт Lens. Компонент и WASM загружаются лениво.
Верхняя строка содержит возврат, закрытие, обновление и SQL без дублирования счётчиков.

**SQL представления → Копировать SQL** копирует полный скрипт активной панели.
Редактор не изменяется. Выполните скрипт целиком на той же неизменённой базе:
он воспроизводит разрез и метрики, включая данные графика. Оформление графика
хранится в настройках Viewer. Служебные DESCRIBE исключаются. Объекты
`lens_replay_*` отделены от живого исследования; повторный запуск заменяет их.
Закомментированные DROP можно выполнить отдельно после использования результата.
Поведение выполнения блоков SQL в редакторе не изменено.

CSV/JSON/NDJSON/Arrow читаются страницами, итог собирается в памяти браузера.
LZ4/ZSTD сжимают буферы Arrow IPC без пересчёта схемы и значений; проверка — PyArrow.
**HTML — штатный экспорт Perspective** активной панели с данными и настройками.
Для открытия нужен интернет: runtime загружается из CDN. Lens больше не встраивает
DuckDB-WASM в HTML. Это экспорт небольших демонстраций, а не архив всей рабочей
области. SQL-выражения и особенности разных движков требуют ручной проверки.
Механизм сохранения файлов приложения не меняется.

Нативный IPC использует существующее подключение и mutex; лимит одного ответа —
100 000 строк и 32 МиБ, не всей исходной таблицы. Настройки SET не меняются.
Perspective может терять точность BIGINT/DECIMAL; интерфейс компонента английский.
Полная совместимость всех возможностей Virtual Server не подтверждена.

Версии зависимостей не изменены: Perspective 5.8.0, JS Arrow 17, Rust arrow-ipc 58
в семействе duckdb-rs 1.10505.0. Обновления SDK требуют перепроверки внутренних API
и совместимости дат. Хуки predev/prestart/prebuild/pretest:analysis теперь только
копируют ZSTD WASM, загружаемый при запросе ZSTD-экспорта.

Базовые проверки: `npm run lint`, `npm run test:analysis`, `npm run test:analysis-sql`,
`npm run build`; существующий `npm test` проверяет остальное приложение.
Analysis native Arrow проверяет реальные Rust IPC и сравнение с WASM-эталоном,
записанным напрямую из IPC, без повторной сериализации разными экземплярами Arrow.
Analysis export compatibility проверяет сжатие через PyArrow и штатный HTML через
file:// в новом браузерном контексте с доступом к CDN. Tauri/Android требуют ручной
проверки интерфейса и сохранения файлов. Подробнее: ANALYSIS_EXPERIMENTAL_EN.md.

## Уточнения интерфейса и HTML

Базовый размер текста Perspective — 14 px. Панель Lens и SQL-окно используют
размер интерфейса Lens и его масштабирование; вокруг Viewer добавлен отступ.
Меню экспорта и копирования ограничиваются видимой областью с прокруткой,
включая масштаб интерфейса Lens. Штатный HTML использует default view исходной
таблицы; адаптер явно подставляет столбцы только для негруппированного вида
без указанной проекции. Исходники SDK и подключение не изменяются.

WASM-дисконнект закрывает соединение, сохраняя экземпляр базы в текущей странице.
Для чистой memory-базы перезагрузите страницу браузера. Перезапуск dev-сервера
сам по себе не уничтожает работающую в уже открытой странице WASM-базу.
