# Исследование данных с Perspective (экспериментально)

Выберите **Исследовать** после **Показать** в меню физической таблицы DuckDB.
Используется текущее подключение Tauri либо WASM (Web/Android). Express/DuckDB,
ClickHouse, VIEW и TEMP не поддерживаются. Произвольный SQL предварительно
сохраните в физическую таблицу через редактор.

**В редактор** сохраняет живое исследование в памяти. Повторное **Исследовать**
для той же таблицы возвращает его; другая таблица заменяет исследование.
Дополнительной строки в редакторе нет. **Закрыть исследование** освобождает Viewer
и клиент, сохраняя исходную таблицу и подключение. При задержке показывается
индикатор без текста в теме Lens. Переподключение закрывает исследование.
**Обновить** перечитывает данные, сохраняя настройки рабочей области. При изменении
схемы может потребоваться закрыть и открыть исследование. Постоянного автосохранения нет.

Новый Viewer использует Pro Light/Pro Dark по теме Lens. Ручной выбор сохраняется
при обновлении. Контейнер наследует шрифт Lens. Компонент и WASM загружаются лениво.
Верхняя строка содержит возврат, закрытие, обновление и SQL без дублирования счётчиков.

**SQL представления → Копировать SQL** копирует полный скрипт активной панели.
Редактор не изменяется. Выполните скрипт целиком на той же неизменённой базе:
он воспроизводит разрез и метрики, включая данные графика. Оформление графика
хранится в настройках Viewer. Служебные DESCRIBE исключаются. Объекты
`lens_replay_*` отделены от живого исследования; повторный запуск заменяет их.
Закомментированные DROP можно выполнить отдельно после использования результата.
Поведение выполнения блоков SQL в редакторе не изменено.

CSV/JSON/NDJSON/Arrow читаются страницами, итог собирается в памяти браузера.
LZ4/ZSTD сжимают буферы Arrow IPC без пересчёта схемы и значений; проверка — PyArrow.
**HTML — штатный экспорт Perspective** активной панели с данными и настройками.
Для открытия нужен интернет: runtime загружается из CDN. Lens больше не встраивает
DuckDB-WASM в HTML. Это экспорт небольших демонстраций, а не архив всей рабочей
области. SQL-выражения и особенности разных движков требуют ручной проверки.
Экспорт из штатного меню использует существующее сохранение Lens: диалог и запись
файла в Tauri, Filesystem/Share в Android, скачивание в Web.

Нативный IPC использует существующее подключение и mutex. В транспорте анализа
нет отдельного лимита Lens по строкам или байтам ответа; лимит обычного результата
редактора 500 000 строк сохраняется. Datagrid запрашивает окна данных, но графики
и экспорт могут запрашивать большие ответы и требуют соответствующих ресурсов.
Это не гарантия защиты от нехватки памяти. Настройки SET не меняются.
Perspective может терять точность BIGINT/DECIMAL; интерфейс компонента английский.
Полная совместимость всех возможностей Virtual Server не подтверждена.

Версии зависимостей не изменены: Perspective 5.8.0, JS Arrow 17, Rust arrow-ipc 58
в семействе duckdb-rs 1.10505.0. Обновления SDK требуют перепроверки внутренних API
и совместимости дат. Хуки predev/prestart/prebuild/pretest:analysis и
pretest:analysis-sql копируют ZSTD WASM и применяют описанный ниже патч DuckDBHandler.

Базовые проверки: `npm run lint`, `npm run test:analysis`, `npm run test:analysis-sql`,
`npm run build`; существующий `npm test` проверяет остальное приложение.
Analysis native Arrow проверяет реальные Rust IPC и сравнение с WASM-эталоном,
записанным напрямую из IPC, без повторной сериализации разными экземплярами Arrow.
Analysis export compatibility проверяет сжатие через PyArrow и штатный HTML через
file:// в новом браузерном контексте с доступом к CDN. Tauri/Android требуют ручной
проверки интерфейса и сохранения файлов. Подробнее: ANALYSIS_EXPERIMENTAL_EN.md.

## Уточнения интерфейса и HTML

Базовый размер текста Perspective — 14 px. Панель Lens и SQL-окно используют
размер интерфейса Lens и его масштабирование; вокруг Viewer добавлен отступ.
Меню экспорта и копирования ограничиваются видимой областью с прокруткой,
включая масштаб интерфейса Lens. Штатный HTML использует default view исходной
таблицы; адаптер явно подставляет столбцы только для негруппированного вида
без указанной проекции. Viewer и подключение не изменяются; патч DuckDBHandler описан ниже.

WASM-дисконнект закрывает соединение, сохраняя экземпляр базы в текущей странице.
Для чистой memory-базы перезагрузите страницу браузера. Перезапуск dev-сервера
сам по себе не уничтожает работающую в уже открытой странице WASM-базу.

Первая панель нового исследования называется по имени таблицы; ручное
переименование сохраняется при обновлении. HTML сохраняет документ штатного SDK
под именем, выбранным в меню. Возврат, источник и SQL находятся слева, сообщения,
обновление и закрытие — справа. Рамка Viewer убрана; фон отступа следует теме
активной панели. Наблюдение за меню не охватывает ячейки таблицы при прокрутке.
Пустой черновик New Column проверяется внутри редактора выражений без запуска
пустого SQL. `countif` предлагается только для BOOLEAN; для количества текстовых
значений используйте `count`. Выражения выполняются DuckDB, поэтому их перенос
в штатный HTML на встроенном движке Perspective требует отдельной проверки.

## Восстановление HTML и длинные заголовки группировок

HTML по-прежнему формируется штатным SDK с исходными данными и настройками
активной панели. Lens исправляет только bootstrap версии 5.8: встроенная таблица
регистрируется под именем из конфигурации, затем последовательно загружаются
клиент и представление. Это сохраняет группировки/фильтры/метрики вместо отката
к плоской таблице. Неизвестный шаблон SDK отклоняется явно. Интернет для CDN нужен,
DuckDB в файл не добавляется. Формулы разных движков по-прежнему требуют проверки.

Для regular-table 0.9.2 добавлен локальный обход: если слишком широкий заголовок
группировки приводит к нулевому окну столбцов при горизонтальной прокрутке,
запрашивается минимум один существующий столбец. Значения и конфигурация не
меняются, горизонтальная виртуализация не отключается. Исправление действует
только на экземпляры Datagrid исследования и снимается при их удалении.
Это внутренний API закреплённой версии, требующий проверки при обновлении SDK.

CI экспорта также сравнивает прокрутку со штатным и Lens-контейнером на длинных
группировках и сохраняет grid-scroll.json. Локально проверен реальный алгоритм
планирования окна; полноценная браузерная/платформенная приёмка остаётся необходимой.

## Проверенная область HTML и графиков

HTML-сводная сохраняет исходные данные и настройки активной панели Datagrid.
Оставлена только проверенная правка bootstrap 5.8: регистрация встроенной таблицы
под именем из конфигурации и последовательное load/restore. Удалены дополнительные
ожидания реестра плагинов, flush/resize/animation frame и собственная панель ошибок,
добавленные при попытках исправить графики. SDK-данные и конфигурация не меняются.

Графики внутри HTML, открываемого как file://, не входят в подтверждённую поддержку:
в CI зафиксирован сбой renderer worker на blob:null. Меню самого SDK не переделано;
наличие HTML-пункта у графика не означает гарантированную работу. Для демонстрации
графика используйте PNG; графики внутри Lens остаются доступны.

PNG/TXT используют штатный plugin export и выбранное имя файла, сохраняя байты.
В обязательном CI остаются HTML Datagrid с проверкой конфигурации/метрик, PNG X Bar
и Y Line из Lens, длинная группировка, сжатие Arrow и отдельный native Arrow CI.
Проверки HTML-графиков удалены из обязательного набора в соответствии с этой областью.
Тест прокрутки загружает Vite-модуль, чтобы импорты пакетов преобразовывались корректно.
Диагностические файлы сохраняются как artifact CI.

Формулы DuckDB и некоторые агрегаты отличаются от встроенного движка HTML.
Даже убранное с оси поле может оставаться в expressions. Автоматического удаления
формул или подмены расчётов нет; HTML с SQL-формулами/оконными вычислениями требует
отдельной проверки и не имеет общей гарантии совместимости.

## Точность SQL и очистка неиспользуемого кода

В DuckDBHandler 5.8.0 удалена одна операция сжатия пробельных символов во всём
SQL: она меняла строковые литералы и имена в кавычках. Скрипт подготовки
`scripts/patch-perspective-duckdb.mjs` воспроизводимо исправляет установленный
ESM-модуль перед запуском/сборкой и тестами анализа. Проверяются версия 5.8.0 и
единственный ожидаемый фрагмент; неизвестная версия или шаблон останавливают
подготовку с ошибкой. Меню, Viewer, SQL-модель и версии зависимостей не меняются.

Интеграционный тест сравнивает фильтры с контрольным SQL для повторных пробелов,
табуляции, переноса строки и апострофа, а также проверяет имена столбцов и
выражения со значимыми пробелами. Эти же случаи включены в native Arrow CI.
Удалены неиспользуемая настройка альтернативного URL ZSTD и невызываемый фильтр
ResizeObserver с его тестом. Сам кодек ZSTD и ленивая загрузка WASM сохранены.

## Диапазоны значений при Split By

При открытии настроек метрики в сводной Lens запрашивает MIN/MAX по её физическим
столбцам `значение|метрика`, объединяя диапазоны в DuckDB. Для группировок ROLLUP
промежуточные итоги исключаются по той же логике, что у SDK; пустые/NULL-данные
возвращают пустой диапазон. Значения таблицы и настройки Viewer не меняются.
Случаи обычной метрики без Split By остаются на штатном обработчике.

Служебные временные таблицы существуют в том же подключении DuckDB, пока живёт
представление. Возврат в редактор сохраняет исследование, а закрытие освобождает
его представления. Дерево схемы автоматически не перечитывается при возврате;
для проверки используйте обновление дерева или запрос
`SELECT database_name, schema_name, table_name FROM duckdb_tables() WHERE temporary AND NOT internal;`.
