## 1. Быстрый старт и работа с движками

Переключение между движками осуществляется в верхней панели управления (селектор **DuckDB** / **ClickHouse**).

### DuckDB (WASM и файловый менеджер VFS)
* **В браузере (WASM)**: база данных выполняется локально в памяти вашего браузера. Вы можете выполнять запросы к файлам `.parquet`, `.csv`, `.json`:
  ```sql
  SELECT * FROM 'data.parquet' LIMIT 50;
  ```
  Файл базы `.duckdb`, открытый в WASM-режиме (в том числе на Android), целиком читается в память: изменения базы живут только в памяти и в сам файл не записываются.
* **Менеджер файлов VFS**: откройте модальное окно VFS через меню настроек или панель файлов и кнопкой «Загрузить файл» добавьте файлы Parquet/CSV в виртуальную файловую систему (перетаскивание файлов в это окно не поддерживается).
* **В десктоп-версии (Tauri)**: запросы обращаются напрямую к файловой системе без ограничений оперативной памяти браузера. Вы можете открывать файлы локальной базы `.duckdb` или читать абсолютные пути с диска.

### ClickHouse (подключение, FORMAT JSON и особенности)
* Переключите селектор движка на **ClickHouse**.
* В окне настроек задайте параметры подключения (хост, порт, пользователь, пароль, БД) или используйте строку подключения URI:
  ```
  https://user:password@clickhouse-host:8443/default
  ```
  > **Подсказка:** Если в пароле есть спецсимволы `@` или `:`, используйте двойное экранирование: `@@` и `::`.
* **Автоматический `FORMAT JSON`**: для `SELECT`, `SHOW`, `DESCRIBE`, `EXPLAIN` клиент добавляет `FORMAT JSON`, если формат не указан (нужен для типов колонок и таблицы). Другой формат (`FORMAT Pretty`, `FORMAT CSV`) не перезаписывается — ответ выводится сырым текстом.
* Приложение поддерживает потоковые запросы `COPY TO / COPY FROM` (в Android-версии `COPY FROM` недоступен), а также отмену выполняющегося запроса (HTTP-запрос обрывается, и ClickHouse останавливает выполнение).
* **Пароль не сохраняется**: хост, пользователь и база запоминаются, а пароль после перезапуска нужно ввести заново. Чтобы не вводить его вручную, сохраните строку подключения (URI с паролем) в Vault (см. раздел 5) под именем с префиксом `ch_`: в форме подключения появится список таких секретов, выбор одного заполняет все поля.

### Ограничение строк выборки (LIMIT в ядре)
* **Встроенный лимит выборки**: для защиты браузера и системы от переполнения памяти при случайном `SELECT *` без фильтрации, приложение по умолчанию ограничивает размер страницы выборки (по умолчанию **100 строк**).
* **Переопределение лимита**:
  1. **Через SQL-запрос**: если в тексте запроса встречается `LIMIT` с числом (например, `LIMIT 500`), ядро считает, что лимит задан вами, и не добавляет `LIMIT 100` на первой странице. Учитывается только `LIMIT` верхнего уровня последнего оператора: `LIMIT` внутри CTE, подзапроса, строки или комментария не считается, и внешний запрос всё равно ограничивается. Таблица при этом всё равно показывает страницу размером с настройку (по умолчанию 100 строк).
  2. **Через настройки интерфейса**: в окне **Settings (Настройки)** можно изменить глобальный размер порции строк (Page Size / Max Rows) отдельно для DuckDB и ClickHouse.
  3. Не более 500 000 строк за один запрос передаётся в интерфейс (десктоп DuckDB, WASM, ClickHouse); если строк больше, запрос заканчивается ошибкой (добавьте LIMIT или сохраните результат через COPY).

### Готовая конфигурация рабочей среды (default_config.json)
Для быстрого старта с настроенными шаблонами, пресетами Excel и сниппетами в репозитории подготовлены эталонные файлы конфигурации:
👉 **Русская версия:** [`docs/default_config.json`](./default_config.json)  
👉 **Английская версия:** [`docs/default_config_en.json`](./default_config_en.json)

В бандл входят правила форматирования SQL, пресеты экспорта Excel, шаблоны автодополнения и быстрых действий, аналитические сниппеты.

**Как импортировать конфигурацию:**
1. Скачайте или скопируйте файл [`docs/default_config.json`](./default_config.json) (или `default_config_en.json`) на свой компьютер.
2. В приложении нажмите `Ctrl + ,` (или иконку шестерёнки вверху), чтобы открыть **Settings (Настройки)**.
3. В нижнем левом углу модального окна нажмите кнопку **Импорт** (иконка со стрелкой вверх).
4. Выберите `.json`-файл конфигурации. Все настройки, шаблоны и пресеты применятся к вашей рабочей среде.

## 2. Редактор SQL и макросы

### Локальные переменные и макросы
Вы можете параметризовать запросы с помощью выражений в комментариях:
```sql
-- {{$limit=200}}
-- {{$status='ACTIVE'}}

SELECT *
FROM orders
WHERE status = {{$status}}
LIMIT {{$limit}};
```
Перед запуском редактор автоматически выполнит безопасную подстановку значений переменных. Системная переменная `{{$timestamp}}` подставляет текущее время в миллисекундах (Unix), а `{{$now}}` — локальное время компьютера строкой `YYYY-MM-DD HH:MM:SS` (без кавычек: `'{{$now}}'`). Значение, заданное через `{{$now=…}}`, имеет приоритет. Если переменная не определена, текст `{{$имя}}` остаётся в запросе как есть и база вернёт синтаксическую ошибку. Значение переменной не может содержать символ `}`.

### Сжатие SQL и кодировки
* **Сжатие в одну строку**: функция компактизации SQL в редакторе автоматически превращает строчные комментарии `--` в блочные `/* */`, чтобы код не сломался при объединении в одну строку.
* **Кодировка Windows-1251 (ANSI)**: если вам нужно открыть старый корпоративный файл скрипта или выгрузку из 1C в кодировке `cp1251`, воспользуйтесь специальной кнопкой импорта Windows-1251 на панели редактора.

### Горячие клавиши и продвинутые операции редактирования
* `Ctrl + Enter` (или `Cmd + Enter`) — в режиме графа (редактор не развёрнут на весь экран) только строит AST-граф, запрос не выполняется; в развёрнутом редакторе выполняет запрос (если включена панель DuckDB или ClickHouse). Выделенный фрагмент выполняется вместо всего текста.
* `Ctrl + Shift + C` — скопировать текст SQL в буфер обмена.
* `Ctrl + Space` — принудительно вызвать всплывающее меню автодополнения (таблицы, колонки схемы, ключевые слова).
* `Ctrl + F` / `Ctrl + H` — открыть встроенную панель поиска / панель поиска и замены в редакторе.
* `Ctrl + Shift + F` — отформатировать SQL-код (с учетом правил регистра и переносов из настроек).
* `Ctrl + Alt + M` — сжать SQL в компактную строку (с автоконвертацией строчных комментариев в блочные).
* `Ctrl + S` (или `Cmd + S`) — сохранить текущий запрос в файл / историю.
* `Ctrl + Shift + S` — сохранить как новый файл.
* `Ctrl + O` — открыть SQL-файл с диска.
* `Ctrl + Shift + K` — сохранить текущую вкладку как шаблон (открывается заполненная форма: название — имя вкладки, описание — первая строка, текст — всё содержимое вкладки).
* `Alt + N` / `Alt + X` — создать / закрыть вкладку (закрытие с подтверждением, если в файле есть несохранённые изменения).
* `Alt + Enter` — выполнить ещё раз последний запрос, выполненный в этой вкладке (независимо от текущего текста и выделения).
* `Ctrl + K` — открыть библиотеку шаблонов (Snippets Manager).
* `Ctrl + \`` (или `Cmd + \``) — открыть / закрыть **Меню действий (Action Menu)**.
* `Ctrl + Q` — вызвать всплывающее меню быстрых действий (Quick Actions) под курсором.
* `Ctrl + /` — закомментировать / раскомментировать строку или блок (`--` / `/* ... */`).
* `Alt + Shift + U` / `Ctrl + Shift + L` — преобразовать выделенный фрагмент (или слово под курсором) в ВЕРХНИЙ / нижний регистр.
* `Alt + Up` / `Alt + Down` — переместить строку или выделенный блок строк вверх / вниз.
* `Ctrl + Shift + V` — вставить содержимое буфера обмена **в конец** каждой выделенной строки.
* `Ctrl + Alt + V` — вставить содержимое буфера обмена **в начало** каждой выделенной строки (полезно для массового обрамления кавычками или префиксами).
* Преобразование регистра, перенос строк (`Alt + Up` / `Alt + Down`) и вставка в начало / конец строк (`Ctrl + Shift + V`, `Ctrl + Alt + V`) действуют только когда фокус в тексте редактора: из поля поиска и замены они документ не меняют.
* `Ctrl + 1` .. `Ctrl + 9` — переход на вкладку с соответствующим номером (модификатор настраивается в Hotkeys).
* **Контекстное меню редактора** (ПКМ): выполнить (выделенное или весь текст), визуализировать, вырезать/копировать/вставить/выделить всё, ВЕРХНИЙ/нижний регистр, закомментировать. ПКМ внутри выделения сохраняет его, вне выделения — переносит курсор в точку клика.
* **Контекстное меню вкладки** (ПКМ по вкладке): сохранить как шаблон, дублировать, переименовать, закрыть остальные (вкладки с несохранёнными изменениями файла остаются открытыми).
* **Управление вкладками мышью**: средний клик (колесиком мыши) по заголовку вкладки закрывает ее; кнопка `+` создает новую вкладку.
* `Alt + W` — переключить перенос длинных строк в редакторе (Wrap).
* `Alt + F` — развернуть редактор на весь экран (Maximize).
* `Alt + T` — переключить тему оформления (Dark / Light).
* `Ctrl + ,` — открыть настройки приложения.
* `Alt + Q` — открыть панель аналитики и графиков (Data Stats).
* `Ctrl + Shift + E` — скопировать результаты выборки в формате TSV в буфер обмена.
* `Ctrl + Alt + E` — сформировать и скачать стилизованный Excel-отчет из текущих результатов.
* `Ctrl + E` — открыть меню экспорта графа (PNG, SVG, JSON, XML, Mermaid, Draw.io).
* `Alt + M` — показать / скрыть миникарту навигатора графа.
* `Ctrl + Alt + S` / `Ctrl + Alt + A` — экспорт / импорт полного рабочего пространства (Workspace JSON).
* `Ctrl + R` — принудительно обновить схему базы данных и список таблиц.
* `Esc` — отменить выполняющийся запрос (остановка гарантирована только в Tauri), сбросить Zoom ячейки или закрыть модальное окно.

## 3. Движок Excel-отчетов и SQL-директивы

При экспорте таблицы результатов в формат `.xlsx` (кнопка **Экспорт в Excel**) вы можете управлять внешним видом, структурой и форматированием документа прямо через комментарии в SQL-коде.

> ⚠️ **Критически важное правило синтаксиса:**  
> Парсер директив Excel ищет параметры **исключительно внутри блочных комментариев `/* ... */`**. Однострочные комментарии `--` парсером Excel **не обрабатываются** (они используются только для локальных переменных редактора). Все директивы отчета необходимо помещать внутрь блока `/* ... */`.

### Справочник директив

| Директива | Назначение |
| :--- | :--- |
| `# Название` | Основной заголовок отчета в первой строке листа |
| `## Подзаголовок` | Подзаголовок с метаданными или периодом |
| `@file: имя` | Переопределяет имя генерируемого файла |
| `@sheet: имя` | Задает имя рабочего листа Excel |
| `@preset: имя` | Применяет пресет оформления по имени (без учёта регистра): встроенный «По умолчанию» или ваш пресет из настроек. Если пресета с таким именем нет, директива молча игнорируется |
| `@totals: функция` | Задаёт функцию нативных итогов (`SUM`, `AVERAGE`/`AVG`, `COUNT`). Строка итогов включена в настройках по умолчанию, столбец итогов — нет; директива их не включает |
| `@split: колонка` | Разбивает результаты на отдельные листы по имени колонки или индексу (1-based) |
| `@group: N` | Группировка строк по имени колонки или ее номеру |
| `@group_cols: N` | Количество колонок категорий слева |
| `@group_hide: true` | Скрывает повторяющиеся значения в группе для создания древовидного вида |
| `@hide: колонка` | Скрывает указанную колонку в Excel-листе |
| `@skip: колонка` | Полностью исключает колонку из генерируемого файла |
| `@protect: пароль` | Защищает лист от случайного редактирования |
| `@excel_save: путь` | *(Десктоп)* Прямое сохранение отчета на диск без диалогового окна |
| `@template: путь` | *(Десктоп)* Заполняет результатом готовый шаблон `.xlsx` с маркером `[[table]]` или `[[rows]]`: оформление ведущей строки применяется ко всем строкам, содержимое ниже сдвигается |
| `@template_values: путь` | *(Десктоп)* Записывает значения в шаблон от клетки маркера; оформление и положение остального содержимого не меняются |

* **`@excel_save` (десктоп)**: Файл создаётся автоматически, когда результат первой страницы приходит в активную вкладку; переходы между страницами, включая возврат на первую, автоэкспорт не повторяют. Повторный запуск запроса, сортировка или фильтрация могут запустить новый экспорт первой страницы. В файл попадают все строки, возвращённые этим выполнением запроса, а не только видимая часть таблицы: обычно одна страница (100 строк по умолчанию), при явном `LIMIT` — до указанного числа. Размер страницы задаётся от 1 до 50 000; `0` означает возврат к 100, а не отсутствие лимита. Для большей выгрузки задайте явный `LIMIT`, учитывая предел результата 500 000 строк и предел Excel 1 500 000 ячеек.

Полный справочник (правила чтения, ограничения, `@excel_save`, `@template`, пример): [`EXCEL_DIRECTIVES.md`](./EXCEL_DIRECTIVES.md).

### Кастомные пресеты Excel и конструктор стилей
Помимо встроенных тем, в окне **Settings $\to$ Excel** доступен полноценный визуальный конструктор оформления:
* Настройка шрифта (Segoe UI, Aptos, Calibri, Arial и др.), высоты строк и кегля заголовков/данных.
* Тонкая настройка цветов: фон и текст заголовков, акцентная заливка итогов, чередование строк («зебра»), цвет линий сетки.
* Включение автофильтра Excel, автоподгона ширины колонок и закрепления шапки (`Freeze Panes`).
* Настройка параметров печати: ориентация листа (книжная/альбомная), масштаб, колонтитулы с датой, временем и номерами страниц.
* **Сохранение в собственные пресеты**: введите имя и нажмите **Сохранить**. Созданный пресет сразу становится доступен для вызова в SQL через `@preset: МойПресет`.
* **Готовый шаблон комментариев**: кнопка «Скопировать шаблон» копирует готовую заготовку блочного комментария со всеми поддерживаемыми директивами для быстрой вставки в скрипт.

## 4. AST-граф и Data Lineage

### Анализ цепочек зависимостей (Lineage)
Для построения графа нажмите кнопку **Visualize** на панели под редактором или используйте горячую клавишу `Ctrl + Enter`:
1. Выделяются все таблицы, представления, подзапросы и CTE (`WITH cte AS (...)`).
2. Строится ориентированный граф зависимостей: каждая карточка — источник (таблица, CTE, производная таблица) или результат (`Projection`).
3. При клике на узел или нажатии кнопки **Focus** подсвечиваются все узлы и рёбра выше и ниже выбранного узла (Data Lineage). Работает по узлам графа внутри одного запроса.

   Кнопка **Monochrome** справа от Focus переводит граф в оттенки серого (одинаково в тёмной и светлой теме, в экспорте тоже). Выбор запоминается.
4. В панели управления графом можно переключать ориентацию (горизонтальная `LR` / вертикальная `TB`).
   * `JOIN` — подписанная стрелка («тип · условие») от присоединяемого источника к тому, к чему он присоединён (определяется по алиасам в `ON`).
   * `WHERE`/`PREWHERE` — чипы на карточке источника, чей алиас упомянут первым; `GROUP BY`, `HAVING`, `QUALIFY`, `ORDER BY`, `LIMIT` — чипы на карточке `Projection`.
   * На карточках источников показаны колонки, упомянутые в запросе как `alias.колонка` (схема БД не запрашивается); у колонок результата — источник.
   * CTE, подзапросы и производные таблицы с несколькими источниками обведены рамкой. Пунктирная стрелка — ссылка (на CTE, производную таблицу, подзапрос), сплошная — поток данных и соединение.
   * Скалярный подзапрос без связи с внешним запросом (например, `total > (SELECT AVG(total) FROM orders)`) связан с карточкой одной пунктирной стрелкой «subquery»: ключа соединения у него нет, это значение-константа; у коррелированного подзапроса условие связи (`k.customer_id = c.id`) видно чипом.
5. **Несколько запросов через `;`**: каждый запрос строится отдельным блоком с заголовком «Query N» и кнопкой «Collapse» (свернуть/развернуть). При `LR` блоки идут друг под другом, при `TB` — друг за другом слева направо. Связи между запросами не рисуются, подсветка lineage ограничена своим запросом. Запрос, который не удалось разобрать, пропускается без сообщения.
6. **Разбор SQL**: используется грамматика PostgreSQL (`node-sql-parser`) плюс эвристический разбор для конструкций, которые он не понимает. Для DuckDB, ClickHouse и Oracle используется тот же разбор, поэтому диалектные конструкции могут отображаться упрощённо.

### Двусторонний Mermaid
* Также поддерживается **обратный импорт и визуализация**: вставьте в редактор текст Mermaid-диаграммы и нажмите кнопку **Markdown** рядом с кнопкой **Visualize** (если текст — чистая Mermaid-диаграмма, она откроется как интерактивный граф):
  ```mermaid
  graph TD
    A[Raw Events] --> B(Kafka Consumer)
    B --> C[(ClickHouse Staging)]
    C --> D[Data Mart]
  ```
  приложение автоматически распарсит его и отобразит в виде интерактивного узлового графа.
* Поддерживаются `flowchart` / `graph`: все фигуры узлов (включая `A@{ shape: cyl, label: "БД" }`), стрелки `-->`, `---`, `-.->`, `==>`, `<-->`, `--x`, `--o`, `~~~`, метки `-->|текст|` и `-- текст -->`, `&`, `;`, комментарии `%%`, кавычки в подписях, кириллические идентификаторы, `subgraph` (в том числе вложенные и связи с подграфом), `classDef` / `class` / `style` / `linkStyle`.
* `erDiagram`: сущности с атрибутами `тип имя PK, FK, UK "комментарий"`, связи `||--o{` с нотацией «воронья лапка», пунктир `..`, подписи, `direction`. Линии строгие: прямые углы, слияния сходятся в шину. `direction` внутри `subgraph` учитывается, если узлы подграфа не связаны с внешними (как в Mermaid). Другие типы диаграмм (`sequenceDiagram`, `gantt` и т. д.) не поддерживаются — приложение сообщит об этом.
* Выражения, которые не удалось разобрать, пропускаются; их список с **номерами строк** показывается над графом, остальная диаграмма строится.

### Markdown-предпросмотр
Выделите фрагмент (или оставьте весь текст) в редакторе и нажмите **Markdown** — в области графа откроется отрисованный документ. Граф при этом скрыт; вернуться к графу можно кнопкой **Visualize**.
* Поддерживаются заголовки, списки (вложенные, нумерованные, чекбоксы), таблицы, цитаты, код, ссылки, картинки (`https:` и `data:image`), `**жирный**`, `*курсив*`, `~~зачёркнутый~~`. «Сырой» HTML не выполняется — он показывается как текст (разрешены только простые теги `<br>`, `<kbd>`, `<sub>`, `<sup>`, `<mark>` и т. п.).
* Блоки ` ```sql ` подсвечиваются; блоки ` ```mermaid ` рисуются диаграммой (flowchart/graph, erDiagram). В углу каждой диаграммы есть кнопка **Открыть как граф** — она строит интерактивный граф из этого блока.
* Текст документа выделяется мышью и копируется. При копировании в буфер попадает HTML для вставки в Word: заголовки, списки, таблицы с границами, код моноширинным шрифтом, диаграммы картинками (светлая палитра). Кнопок и подписей языка в копию не попадает.
* **Экспорт**: в меню «Экспорт» доступны `PNG Image` и `JPEG Image` — в картинку попадает весь документ целиком (шириной 900 px, цвета текущей темы), независимо от размера окна. Остальные пункты меню в режиме документа неактивны. Слишком длинный документ (сотни экранов) не экспортируется целиком — выделите часть текста.

## 5. Безопасный Vault и подстановка секретов

В приложение встроен зашифрованный сейф секретов (**Encrypted Vault**), использующий шифрование **AES-256-GCM** через Web Crypto API:
1. Откройте **Настройки $\to$ «Элементы UI»**, блок **«Ключи и секреты (PIN-код)»** (внизу вкладки), и задайте PIN-код (мастер-пароль).
2. Добавьте секреты, например `CLICKHOUSE_PASS` или `PROD_TOKEN`.
3. В коде ваших SQL-запросов вы можете ссылаться на сохраненные ключи:
   ```sql
   SELECT * 
   FROM read_parquet('https://my-bucket.s3.amazonaws.com/data.parquet?token={{PROD_TOKEN}}');
   ```
4. При выполнении запроса `{{ИМЯ}}` заменяется значением секрета непосредственно перед отправкой запроса; в тексте вкладки, истории версий и сниппетах остаётся `{{ИМЯ}}`.
5. После ввода PIN разблокировка действует 12 часов. Истечение срока проверяется при следующем обращении к состоянию Vault; тогда доступ блокируется и его состояние в памяти очищается. Отдельного таймера блокировки, таймера неактивности и настройки срока нет. Заблокировать его раньше можно кнопкой «Заблокировать» в разделе Vault. Разблокировка действует только в текущем запуске приложения.
6. Если в тексте запроса встречается `{{` (в том числе нераскрытая `{{$переменная}}`), а хранилище заблокировано, запрос не выполняется и появляется сообщение о заблокированном хранилище.

## 6. Action Menu, сниппеты и фоновые пайплайны (@job)

Вкладка **Меню действий (Action Menu)** — это интерактивная панель карточек и no-code пайплайнов для часто выполняемых аналитических сценариев.

### Как открыть Меню действий:
1. **Через горячую клавишу**: нажмите `Ctrl + \`` (или `Cmd + \`` на macOS), чтобы переключиться на вкладку Меню действий из любого места приложения. Повторное нажатие вернёт вас к предыдущей активной вкладке с SQL-запросом.
2. **Через панель вкладок**: в полноэкранном режиме редактора в строке вкладок самая первая левая статическая вкладка с иконкой кода `<>` (слева от вкладки 1) открывает **Action Menu**.
3. **Библиотека сниппетов (каталог шаблонов)**: вызывается сочетанием клавиш `Ctrl + K` либо кнопкой с иконкой слоёв на панели инструментов редактора. В окне библиотеки шаблонов также доступна полная категория «Меню действий».

### Возможности Action Menu:
* **Быстрое редактирование карточки по двойному клику**: двойной клик левой кнопкой мыши по любой карточке в Action Menu открывает окно редактирования этого шаблона в Конструкторе сниппетов.
* **Интерактивные параметры прямо на карточке**: если в запросе используются переменные вида `{{$Имя=значение}}`, карточка отобразит поля ввода прямо перед запуском без необходимости редактировать SQL вручную.
* **Быстрый запуск (`Play`)**: выполнение действия на активном движке (DuckDB / ClickHouse) по клику.
* Добавляйте часто используемые запросы в **Избранное** (иконка звёздочки).
* **Многокомандные пайплайны (`-- @job`)**:
  Если ваш сниппет содержит несколько команд через точку с запятой, добавьте в начало директиву `-- @job`:
  ```sql
  -- @job: Обновление витрины данных
  CREATE OR REPLACE TABLE daily_summary AS 
  SELECT today() AS dt, count(*) AS total_events FROM events;

  OPTIMIZE TABLE daily_summary FINAL;
  ```
  Приложение выполнит команды по очереди: все, кроме последней, как подготовительные (результат не показывается), а результат последней отображается в таблице. При ошибке выполнение останавливается. Последовательно запускается любой сниппет из нескольких команд, директива `-- @job` нужна для пометки и фильтра «Jobs».
* **Выполнение выделенного фрагмента**: правый клик по кнопке запуска (под редактором) открывает меню с пунктами «Последовательное выполнение» (как выше) и «Параллельное выполнение» (команды запускаются одновременно, вместо результата показывается таблица статусов `Query` / `Status` для каждой команды).

### Экспорт библиотеки шаблонов и истории версий:
1. **Экспорт библиотеки шаблонов (Snippets Manager — `Ctrl + K`)**:
   * **Экспорт в ZIP**: кнопка **«Экспорт ZIP»** упаковывает все шаблоны в структурированный архив. Внутри архива создаются папки по категориям, а также папки `Избранное` и `Jobs`. Каждый файл сохраняется с расширением `.sql` (или `.py`, `.sh`, `.md` в зависимости от заголовка) и содержит метаданные диалекта и описания в комментариях.
   * **Экспорт в JSON**: сохраняет единый файл со всеми шаблонами для быстрого бэкапа или переноса в другое рабочее пространство.
2. **Экспорт истории версий кода (Version History — иконка часов/истории)**:
   * **Экспорт в ZIP**: выгружает снимки кода в архив с иерархией каталогов `Автосохранение/` или `Ручной снимок/`, с подпапками по пользовательским меткам и файлами с датой и временем создания.
   * **Экспорт в JSON**: полный дамп истории версий с таймстемпами для восстановления.

## 7. Инспекция данных, статистика и экспорт

Таблица результатов (**DataStatsViewer**) разработана для аналитики данных любого объема:
* **Транспонирование (`Row ↔ Col`)**: быстрый поворот таблицы для детального изучения единичных широких строк.
* **Cell Zoom**: детальный просмотр содержимого длинных строк, форматированного JSON и массивов в отдельном окне.
* **Быстрые контекстные фильтры**:
  * Кликните правой кнопкой мыши или по значению в ячейке, чтобы применить фильтр (`=`, `!=`, `LIKE`, `IS NULL`, `IS NOT NULL`).
  * Для предотвращения потери исходного сложного запроса отфильтрованная выборка автоматически открывается в **новой связанной вкладке** с сохранением базового SQL.
* **Сортировка столбцов**: клик по заголовку сортирует выборку на уровне SQL-запроса (`ASC` / `DESC`) с безопасным оборачиванием.
* **Аналитическая панель и графики (`Alt + Q`)**:
  * Переключение между списком статистики, столбчатой диаграммой, линейным графиком и круговой диаграммой (Pie Chart).
  * **Режимы Bar Chart**: поддержка как вертикального, так и горизонтального расположения столбцов (клик по кнопке Bar переключает ориентацию).
  * **Копирование графика как картинки**: нажмите иконку копирования над областью графика, чтобы скопировать график в буфер обмена как PNG (масштаб пикселей 2x).
  * **Глубокая статистика по колонкам (Columns Stats / Aggregation)**: по кнопке «Обновить по БД» запрашивает `total_count`, `null_count`, `null_percent`, `unique_count`, `sum`; среднее вычисляется в клиенте как сумма / число непустых значений. Запрос не ограничен текущей страницей; лимит строк источника выбирается в панели: 1M по умолчанию, 10M, 50M, 100M или ALL. Min/max и другие показатели загруженного результата относятся к локальному анализу; отдельный режим `SUMMARIZE` показывает статистику, возвращённую DuckDB.
* **Копирование таблицы в буфер обмена**:
  * Кнопка **Copy as Image**: скопировать видимую часть таблицы результатов в виде готового PNG высокого разрешения.
  * `Ctrl + Shift + E` — скопировать всю текущую страницу выборки в формате TSV (табуляция) для вставки в Google Таблицы или Excel.

## 8. Настройки, кастомизация интерфейса и синхронизация

Окно настроек вызывается комбинацией `Ctrl + ,` или кнопкой-шестерёнкой на верхней панели.

### Параметры движка DuckDB (Память, Потоки, Init SQL, Расширения)
В разделе **Элементы UI** при включенном блоке DuckDB доступны тонкие параметры подключения:
* **Memory Limit**: лимит выделения оперативной памяти для DuckDB (по умолчанию `8GB`).
* **Temp Directory**: путь к каталогу для временных файлов при обработке больших выборок (по умолчанию `./tmp`).
* **Extensions Dir**: директория хранения и загрузки локальных расширений (по умолчанию `./extensions`).
* **Threads**: число рабочих потоков CPU (`0` — авто-определение всеми доступными ядрами процессора).
* **Init SQL Script (`duckDbInitSql`)**: стартовый SQL-скрипт, выполняемый автоматически при каждом подключении (например, `LOAD 'spatial';` или установка таймзоны `SET TimeZone='UTC';`).
* **allow_unsigned_extensions**: разрешение загрузки неподписанных расширений сообщества.
* Параметры движка применяются в момент подключения к базе: изменённые значения подействуют при следующем подключении, а не сразу в открытой сессии.
* Пути по умолчанию (`./tmp`, `./extensions`) относительные и считаются от рабочего каталога приложения; при установке в защищённую папку задайте абсолютные пути. Ошибки в параметрах и в Init SQL приложение не показывает: если расширение не загрузилось, проверьте скрипт, выполнив его вручную в редакторе.

#### Собственные расширения DuckDB
Поместите файлы `.duckdb_extension` в **Extensions Dir**, включите `allow_unsigned_extensions` (если расширение не подписано DuckDB Labs) и добавьте в **Init SQL Script** `LOAD 'имя_расширения';`. Список протестированных расширений: [**docs/extension_list.md**](./extension_list.md).

### Кастомизация автодополнения и Quick Actions
* **Шаблоны автодополнения**: вкладка **Форматы** позволяет добавлять собственные ключевые слова, макросы и сниппеты, которые всплывают в выпадающем подсказчике редактора при вводе.
* **Quick Actions**: шаблоны быстрых действий для контекстного меню схемы (например, «Посчитать дубликаты», «Копировать таблицу», «Экспорт в Parquet»). Поддерживают плейсхолдер `{table}` для автоматической подстановки выбранного имени таблицы.
* **Схема и файлы**: кнопка с иконкой базы данных открывает панель, внизу которой дерево файлов. Корень задаётся в Настройках («Корневая папка дерева файлов»), иначе берётся папка открытой БД, затем домашняя. В браузере и на Android показан список виртуальной ФС DuckDB-WASM (только перетаскивание).
  * Папки читаются при раскрытии; список обновляется кнопкой и при возврате в окно (не чаще раза в 10 с). `Ctrl + R` обновляет только схему БД.
  * Над деревом — поиск (фильтрует только загруженное, папок не раскрывает) и сортировка по имени, дате или размеру (повторный клик меняет направление, папки всегда первыми; выбор запоминается).
  * Перетаскивание файла в редактор вставляет его путь в одинарных кавычках; папка ничего не вставляет.
  * Десктоп: двойной клик открывает текстовые файлы (`sql, md, txt, py, sh, yml, yaml, toml, ini, log`) вкладкой, документы Office и PDF — внешней программой.
  * Десктоп, правый клик: «Открыть с помощью…» (только файлы; Windows и macOS), «Показать в проводнике», «Переименовать» (прямо в строке; Enter применяет, Esc отменяет), «Удалить (в корзину ОС)» без подтверждения.
  * Файл или папку можно перетащить в другую папку дерева (на пустое место — в корневую). Если перенос невозможен (папка в саму себя или во вложенную, имя занято, другой диск), цель на 1–2 с краснеет, ничего не меняется. Открытые вкладки следуют за переименованием и переносом; у удалённого файла вкладка остаётся несохранённой.

### Переназначение горячих клавиш (Hotkeys)
На вкладке **Hotkeys** можно полностью переназначить клавиатурные сочетания под привычные вам комбинации (DBeaver, DataGrip, VS Code). Достаточно кликнуть по кнопке сочетания и нажать желаемые клавиши.

### Автосинхронизация рабочего пространства (Workspace Sync Path)
В десктопной версии (Tauri) поддерживается автоматическая синхронизация настроек и вкладок между несколькими устройствами:
1. В настройках укажите путь к файлу в синхронизируемой папке (например, `D:\Dropbox\workspace.json` или `/Users/name/YandexDisk/lens_workspace.json`).
2. Приложение при запуске автоматически считывает обновлённую версию бандла, если она новее локальной, сохраняя при этом аппаратно-зависимые параметры конкретного ПК.
3. Побеждает более новый файл: если синхронизируемый файл был обновлён с другого компьютера после вашей последней синхронизации, локальные правки не записываются в него и при следующем запуске заменяются содержимым файла. Секреты Vault и пароль ClickHouse в файл не попадают.
4. Ручной экспорт и импорт полного рабочего пространства доступны через кнопки **Экспорт** и **Импорт** в подвале окна настроек.

### Узкий экран и Android
Раскладка для узких окон включается по ширине окна (до 767 px), а не по платформе: её можно проверить на десктопе, сузив окно.
* На экране виден либо редактор, либо граф. **Visualize** и **Markdown** показывают граф; вернуться к редактору можно кнопкой «Показать/скрыть панель редактора» в шапке графа (на узком экране она показана всегда).
* Шапки и нижние панели — одна строка, которая прокручивается пальцем (полосы прокрутки нет): если справа обрезана кнопка, там есть ещё кнопки. Меню «Экспорт» и «Подключение» открываются под кнопкой, «Пресеты» — нижним листом.
* В развёрнутом редакторе панель «Схема и файлы» выезжает справа: открывается кнопкой со значком базы данных, закрывается крестиком в её шапке. По умолчанию на узком экране включён перенос строк, миникарта графа скрыта.
* Окна «Настройки», «Библиотека шаблонов» и «История версий» подстраиваются под ширину: вкладки настроек показаны значками, у библиотеки и истории короткие заголовки, история показывает список версий над кодом.
* Системная кнопка «Назад» на Android (только в приложении) последовательно закрывает: открытые меню и подтверждения → окна (настройки, библиотека, история, подключения, файловый менеджер WASM) → выбранную ячейку → таблицу результата в развёрнутом редакторе (сначала уменьшает, затем сворачивает); если закрывать нечего, приложение сворачивается. Запущенный запрос кнопка «Назад» не отменяет.
* Окно десктопной версии уже 768 px получит ту же узкую раскладку.
